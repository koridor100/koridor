# 🚪 100 КОРИДОР — Фан-хаб Doors (Roblox)

**КОРИДОР** — это стильный, атмосферный веб-интерфейс и фан-хаб, посвященный популярной хоррор-игре **Doors** на платформе Roblox. 

Проект сочетает в себе справочную вики, симулятор виртуальных кейсов, трекер личного прогресса и интерактивное комьюнити-сообщество.

---

## ✨ Основные возможности

### 🕯️ 1. Открытие кейсов (Doors Case Simulator)
- Виртуальная валюта — **Свечи** (получаются ежедневно и не требуют реальных вложений).
- Плавная анимированная рулетка с выпадением предметов разной редкости (*Common, Uncommon, Rare, Mythic*).
- Автоматическое сохранение полученных предметов в персональный инвентарь.

### 📊 2. Трекер и статистика забегов
- Ручной ввод результатов прохождения (достигнутый этаж 1–100, количество смертей, время, режим игры *Solo/Party*, заметки).
- Автоматический расчет метрик: среднее число смертей, лучший этаж, общее количество забегов.
- Сохранение истории каждого прохождения.

### 📖 3. Энциклопедия сущностей и Комьюнити
- Фильтрация монстров по всем актуальным локациям:
  - **Отель (Hotel)**
  - **Шахты (Mines / Subfloor)**
  - **Бэкдор (Backdoor)**
  - **Great Outdoors**
  - **Архивы (The Archives)**
  - **Лестничный пролёт (The Stairwell)**
- Интерактивная зона **Обсуждений** для обмена сообщениями между пользователями.

### 🏆 4. Интерактивный викторина-тест на ранг
- Опросник из 5 ключевых вопросов о механиках игры.
- Определение вашего уровня (*Новичок, Рядовой, Ветеран, Мастер*).
- Возможность публикации результатов в глобальную **Таблицу лидеров**.

### 💡 5. Актуальный гайд по выживанию (Survival Guide)
- Подробные инструкции по каждому монстру: визуальные/звуковые сигналы и тактика спасения.
- Полная адаптация под свежие обновления игры, включая **The Archives** и **The Stairwell**.

---

## 🎨 Дизайн и атмосфера

Интерфейс оформлен в узнаваемой стилистике **Doors**:
- **Атмосферные эффекты:** виньетка, легкий пленочный шум (grain), динамическое тление искр, мерцание коридорного освещения.
- **Интерфейс «Дверей»:** навигация выполнена в виде стилизованных дверных табличек.
- **Адаптивный стек:** корректное отображение как на ПК, так и на мобильных устройствах.

---

## 🛠️ Технологический стек

- **HTML5 & CSS3:** кастомная верстка, CSS Custom Properties, анимации и градиенты без внешних тяжелых библиотек.
- **Vanilla JavaScript (ES6+):** клиентская логика рулетки, калькулятор ранга, динамические фильтры.
- **Storage Layer (Async Storage / LocalStorage):** сохранение баланса, инвентаря, забегов и публичных сообщений непосредственно в локальном окружении или артефактном хранилище.

## 🚀 Быстрый запуск

Данный проект полностью автономный и не требует установки бэкенда или дополнительной сборки (Node.js/npm).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/koridor-doors-hub.git
   ```
2. Откройте файл `index.html` в любом современном веб-браузере.
